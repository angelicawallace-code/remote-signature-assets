# remote-signature-assets

Static brand image assets (Remote logo mark, social icons, layout background
illustrations) used by an internal Gmail signature generator tool.

Referenced directly via `raw.githubusercontent.com` URLs from the generated
email HTML — these files must stay publicly fetchable (no auth) so the
images render for every recipient of a signed email, not just Remote
employees. Nothing here is sensitive; it's the same brand imagery already
visible on remote.com and in any email these signatures are used in.

Do not rename existing files/paths without also updating the generator.
